## 4. Ready-to-run download script for Codex (Linux/macOS)

Run in scratch storage, not directly over the GitHub source tree.

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="${1:-./VIDEO007_STAGE13R_SOURCES}"
mkdir -p "$ROOT"/{archives,original_pdfs,extracted,manifests}
CDN='https://d2ol7oe51mr4n9.cloudfront.net/user_3KfJBJG9d4fKmhfgQcZhmVmPdh1'

fetch_zip() {
  local name="$1" remote="$2"
  echo "Downloading $name"
  curl -fL --retry 3 --retry-delay 2 "$remote" -o "$ROOT/archives/$name.zip"
  unzip -tqq "$ROOT/archives/$name.zip"
  mkdir -p "$ROOT/extracted/$name"
  unzip -oq "$ROOT/archives/$name.zip" -d "$ROOT/extracted/$name"
}

fetch_zip 'VIDEO_36' "$CDN/d4a6bde1-0984-485c-99db-05ff3e363276.zip"
fetch_zip 'VIDEO_24' "$CDN/cc05d9d8-d114-4f11-a673-4753273a7450.zip"
fetch_zip 'VIDEO_7' "$CDN/50c0997a-ab55-49aa-a3b2-f5ada4e304f4.zip"
fetch_zip 'APPLE_WWDC_6' "$CDN/09059f5c-2bd8-40a4-8a1c-0c7a2533e7da.zip"
fetch_zip 'PHOTO_72' "$CDN/3ad6fcd7-24a7-4fa6-9ab5-9301f0d65b91.zip"
fetch_zip 'ECF_SOURCE_PACK' "$CDN/c5ac1993-95c2-40fa-8180-3414b5ed9d51.zip"
fetch_zip 'SOURCE_VISUAL_QC' "$CDN/6a8e2d59-3c0e-4a52-a0d1-90ce26b0b117.zip"

CASE='https://storage.courtlistener.com/recap/gov.uscourts.cand.474095'
for n in 1 59 97 143 175 176 188 189; do
  curl -fL --retry 3 "$CASE/gov.uscourts.cand.474095.${n}.0.pdf" -o "$ROOT/original_pdfs/ECF${n}.pdf"
done
curl -fL --retry 3 'https://9to5mac.com/wp-content/uploads/sites/6/2026/10/gov.uscourts.cand_.474095.177.0.pdf' -o "$ROOT/original_pdfs/ECF177.pdf"

(cd "$ROOT" && find archives original_pdfs -type f -print0 | sort -z | xargs -0 sha256sum > manifests/DOWNLOADED_SHA256.txt)
echo 'DONE: check contents, deduplicate by SHA-256, then follow GitHub editorial QC.'
```

Downloading the native PDFs separately is optional if the PDFs in the ZIP are already checked and the original hashes match.

# Stage 12D — Template Families

Status: **LOCKED**

These seven families are the repeatable production grammar for VIDEO_001. They are not rigid copy-paste cards; each family may vary composition while preserving hierarchy, source truth and subtitle safety.

## T01 — Evidence Frame
Use for: physical evidence, threatening-message context, authentic shock-object material.

Structure:
- authentic/source-safe evidence image or contextual real image is dominant;
- short evidence label above;
- one factual line maximum;
- source attribution above the subtitle-safe boundary;
- lower 20% clear.

Variants:
- PHYSICAL_EVIDENCE
- AUTHENTIC_SHOCK_EVIDENCE
- MESSAGE_OR_HARASSMENT_EVIDENCE

Rules:
- serious documentary treatment;
- no horror grading;
- no invented evidence markers;
- authentic DOJ/FBI image beats any reconstruction.

## T02 — Executive Dossier
Use for: Wenig / Wymer / Jones / executive chain / civil-vs-criminal status.

Structure:
- real licensed portrait when available, otherwise document-forward dossier;
- name + role;
- one or two exact legal/status lines;
- court/source backing;
- caveat: surviving claim ≠ liability where applicable.

Variants:
- EXECUTIVE_CHAIN_DOSSIER
- EXECUTIVE_LEGAL_STATUS
- COMPANY_STATEMENT_STATUS

Rules:
- no generated likeness;
- no guilt-by-red-color implication;
- criminal/civil status must be explicit.

## T03 — Court Document Highlight
Use for: court order, DPA, Criminal Information, complaint, exact internal quote, legal clarifier.

Structure:
- real source crop/document 50–70% of factual area;
- exact line highlighted;
- editor headline separate from source;
- source/date/case context;
- optional small legal clarification.

Variants:
- QUOTE_HIGHLIGHT
- DPA_LEGAL_DOCUMENT
- COURT_ORDER_OR_LEGAL_CLARIFIER

Rules:
- never rewrite text inside the source document;
- no fake docket/filing;
- one highlighted passage at a time.

## T04 — Money / Settlement Graphic
Use for: $55.7M package, $48.7M compensation, $7M charity, payor breakdown, $3M DPA penalty, cost synthesis.

Structure:
- one dominant number;
- one clean breakdown layer;
- source-backed labels;
- explicit legal caveat when necessary.

Variants:
- SETTLEMENT_BREAKDOWN
- PENALTY_OR_COST

Mandatory rule:
**$3M criminal DPA penalty stays visually separate from the $55.7M civil settlement package.**
**$55.7M is never presented as a judgment.**

## T05 — Geography / Map Frame
Use for: San Jose → Massachusetts, Natick/Boston context, operation geography, corporate/location establishing.

Structure:
- Natural Earth/editor-built map or real location image;
- limited route line;
- 2–4 location labels maximum;
- optional one real location photo;
- no victim address.

Variants:
- GEOGRAPHY_CONTEXT
- OPERATION_GEOGRAPHY
- CORPORATE_OR_LOCATION_ESTABLISHING

Rules:
- map routes show story geography, not invented surveillance telemetry;
- GPS event must say **ATTEMPTED — NOT INSTALLED** where material.

## T06 — Timeline / Operation Frame
Use for: sequence, escalation, investigation, settlement failure/reopening, final synthesis.

Structure:
- 3–5 dated events maximum;
- vertical or horizontal date spine;
- one source-backed icon/photo/crop per major event when useful;
- causal flow, not a dashboard.

Variants:
- OPERATION_OR_CASE_TIMELINE
- SETTLEMENT_TIMELINE
- FINAL_SYNTHESIS_TIMELINE

Rules:
- do not compress the entire case into one unreadable frame;
- use progressive reveals in editing.

## T07 — Sentencing / Participants Board
Use for: the seven prosecuted participants, guilty pleas, person-specific sentences/accountability.

Structure:
- participant names;
- role/status;
- exact plea/sentence only where source supports it;
- DOJ/court document backing;
- paper/dossier visual language.

Variants:
- PARTICIPANTS_ACCOUNTABILITY_BOARD
- SENTENCE_DETAIL

Rules:
- no unsourced portraits;
- if a usable real portrait is unavailable, use name/role + DOJ/court source treatment rather than inventing a face;
- guilty plea and sentence data remain person-specific.

## Cross-family rule

Every family obeys `12D_STYLE_BIBLE.md`, especially:
- bottom 20% 16:9 subtitle-safe;
- bottom 22% 9:16 subtitle/UI-safe;
- authentic source > real context > editor GFX > reconstruction;
- no three identical compositions in sequence;
- no card-grid UI as the default visual system.

# Stage 12F-R6 — Prompt Execution Rules

## Why R6 exists
R5 visual QC exposed three execution defects:
1. style-reference subject leakage (B018);
2. dense document/reference text surviving into legal frames (B007/B008);
3. semantically late source binding (B041).

R6 corrects these at the input/prompt level before any further paid generation.

## Hard execution order
For every Higgsfield job:
1. attach the beat's **factual source images first**;
2. attach the **style reference last**;
3. the script/exact text outrank every image reference.

## Style-reference isolation
The style reference is non-factual.
It may contribute only:
- palette;
- typography scale;
- paper layering;
- texture;
- spacing;
- framing;
- line weight;
- restrained red accent.

It must never contribute:
- its people;
- objects;
- evidence subject;
- logo;
- location;
- document content;
- quote;
- headline wording.

If a style subject is absent from factual sources, it is forbidden in output.

## Document input rule
Raw PDF/HTML is never attached directly to Higgsfield.
Text-heavy image crops must be tightened **before the job** to the exact one-line/short-passage evidence needed for that beat.
No full-page body-text references for generation.

## Subtitle rule
Bottom **22%** is the R6 hard quiet zone.

## Test10 corrective locks
- B007: one tight DOJ excerpt only.
- B008: tiny DPA excerpts for $3M / monitor / admitted facts; no dense legal panel.
- B018: quote crop only; dossier style reference; absolutely no pig-mask imagery.
- B024: security-chain cue, not generic LEGAL STATUS.
- B041: Natick/location + physical-surveillance → police chronology; no GPS tracker hero.

## Spend
R6 prompt rewrite authorizes **zero** generation jobs.

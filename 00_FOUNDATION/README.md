# 00_FOUNDATION — Canonical Channel Base

This folder contains the smallest set of stable decisions every future episode and agent may rely on.

Allowed: positioning, content pillars, topic-qualification locks, launch queue, source hierarchy, legal-language locks, review standards, brand/voice lock state and approved channel-wide production invariants.

Forbidden: episode research, filings, script text, screenshots, generated assets, episode QA or analytics.

## Canonical files
- `CHANNEL_LOCKS.md` — format and editorial direction.
- `POSITIONING.md` — viewer-facing niche promise.
- `CONTENT_PILLARS.md` — core/secondary content pillars.
- `TOPIC_QUALIFICATION_LOCK.md` — hard GO/HOLD/NO-GO rules.
- `LAUNCH_BATCH.csv` — canonical current launch shortlist/order.
- `SOURCE_HIERARCHY.md` — evidence priority.
- `LEGAL_LANGUAGE_LOCKS.md` — allegation/ruling/settlement/etc distinctions.
- `REVIEW_METRICS.md` — canonical quality thresholds.
- `BRAND_LOCK.md` — public brand lock state.
- `VOICE_LOCK.md` — narrator lock state.

Foundation wins over more detailed channel bibles until the owner explicitly changes a lock.

# Voice Lock

Status: **UNLOCKED / SCRIPT #1 LOCKED — READY FOR VOICE TESTS**

No narrator identity from another channel/project is inherited automatically.

## Sequence rule

Voice selection must **not** happen before the first script establishes the real channel cadence.

Canonical order:
1. Lock public visual assets.
2. Lock the first 10 topics.
3. Research Topic #1.
4. Write and pass Script #1 through fact/legal + performance review.
5. Lock Script #1.
6. Only then test, select and lock the channel narrator/voice.
7. Produce Voice Script / final audio.

## Why

The narrator must fit the actual writing:
- sentence length;
- pacing;
- tension curve;
- documentary restraint;
- pronunciation load;
- legal/business density;
- emotional range;
- humor/dryness level;
- transition rhythm.

Choosing the voice earlier risks forcing the script to fit a voice rather than selecting a voice that serves the channel's writing.

## Requirements for eventual lock
- English narration suitable for a US audience;
- documentary/storytelling delivery, controlled rather than announcer-like;
- credible with business/legal material without pretending to be a lawyer, journalist or named real expert;
- consistent across long-form episodes;
- strong performance on the locked Script #1;
- provider/model/voice ID and approved reference recorded here before final Stage 10 audio generation.

# Naming

- Video folders: `VIDEO_001_SLUG` through `VIDEO_999_SLUG`.
- Video IDs are immutable and never reused.
- Scene IDs: `SC001`, `SC002`, ...
- Source IDs: `SRC001`, `SRC002`, ...
- Claim IDs: `CLM001`, `CLM002`, ...
- Case-event IDs: `EVT001`, `EVT002`, ...
- QA issue IDs: `QA001`, `QA002`, ...
- Asset IDs: `V001_SC001_IMG_A` or globally unique shared IDs.

Use stable canonical filenames. Do not create `final_final_v7`; record revisions in VERSION_LOG, manifest versions and Git history.

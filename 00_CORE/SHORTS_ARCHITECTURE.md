# Shorts Architecture — Long-Form-First, Cut-Ready by Design

## Hard requirement
Every long-form WHAT IT COST episode must be written so canonical Shorts can be extracted directly from the finished long-form narration.

Default target:
- 6–10 short-ready segments per long-form episode;
- preferred duration 25–60 seconds; up to ~75 seconds when a complete factual/legal unit needs it;
- one continuous time range per Short;
- sentence-boundary cuts;
- no reordered narration;
- no new narration required;
- no stitching distant lines for the canonical cut-ready Short.

## Writing rule
Each candidate must contain inside the same continuous extract:
1. standalone hook;
2. enough context to identify the event/entity;
3. one clear conflict, number, mechanism, legal distinction or reveal;
4. payoff before the cut ends;
5. any attribution/caveat needed to preserve factual/legal meaning.

## Legal rule
Every Short is reviewed in isolation. Extraction must not convert allegation to fact, charge to conviction, surviving claim to liability, settlement to judgment, or attempted act to completed act.

## Stage contract
- Stage 02: identify 6–10 short-ready story units.
- Stage 03: create 03_SHORTS_MAP.csv from contiguous script ranges; revise long-form wording until selected zones stand alone.
- Stage 04: fact/legal review each proposed extract independently.
- Stage 05: repair weak context/hook/payoff inside the long-form itself.
- Stage 06: review first-line hook, standalone clarity, density, payoff and visualizability.
- Stage 07: lock 07_SHORTS_LOCK.csv with the final script. Normal Stage 07 PASS requires it unless owner explicitly waives it.
- Stages 08–10: canonical Shorts use the same narration; no separate TTS.
- Stage 11: derive exact final-master timestamps in 11_SHORTS_CUT_MAP.csv.
- Stage 12: tag every Short-used beat with short_ids and a 9:16-safe visual strategy.
- Stage 15: build 9:16 cuts from those exact ranges; same narration/story, reframe or alternate layout only.
- Stage 16: refresh facts/legal posture for every Short independently.
- Stage 17: package each Short separately without strengthening the claim.

## Success condition
Once the long-form master exists, canonical Shorts are a cut/reframe/caption job, not a new writing or voice-production job.

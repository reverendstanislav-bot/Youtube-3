# Agent Playbook — Maker → Critics → Lead

## Pattern
1. Maker creates the stage artifact.
2. Independent critics inspect the artifact without relying on maker rationale.
3. Lead synthesizes, resolves issues and changes state only after the gate passes.

## Specialist map
### Topic / research
- primary-source researcher;
- docket/case-status researcher;
- company/industry researcher;
- competitor/YouTube-treatment researcher;
- narrative/visual researcher.

### Fact/legal review
- claims-ledger critic;
- chronology/procedure critic;
- adverse-position/fairness critic;
- numbers/quotes critic.

### Script
- hook/retention critic;
- story/causality critic;
- legal/factual critic;
- visualizability critic;
- differentiation/packaging critic.

### Final release
A fresh reviewer checks edited narration/graphics/title/thumbnail against current legal status and source record.

## Required issue format
`SEVERITY | stage/lens | exact location | diagnosis | evidence/reason | acceptance criterion`

Severity: BLOCKER / HIGH / MEDIUM / LOW.

## Stop conditions
Stop rather than improvise when:
- a material primary/current source is missing;
- a legal status is unresolved and changes wording;
- an upstream artifact is not locked;
- a title/thumbnail accusation exceeds evidence;
- a requested step would silently change a channel lock;
- current gate is FAIL.

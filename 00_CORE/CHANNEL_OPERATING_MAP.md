# Channel Operating Map

## Layer 1 — Channel truth
`00_FOUNDATION/`
Positioning, pillars, qualification locks, source hierarchy, legal-language rules, launch shortlist and eventual brand/voice locks.

## Layer 2 — Operating system
`00_CORE/`
Schemas, statuses, gates, source/legal rules, task recipes, production pipeline and audit logic.

## Layer 3 — Channel craft
`01_CHANNEL/`
Storytelling, fact-checking, competitor analysis, source capture, legal wording, visual, voice, title and thumbnail systems.

## Layer 4 — Portfolio
`02_PIPELINE/`
Unassigned topic candidates + locator for real video packages.

## Layer 5 — Episode truth
`03_VIDEOS/VIDEO_0XX_*/`
Everything specific to one video: research, evidence, claims, chronology, scripts, visuals, assets, packaging, upload and analytics.

## Layer 6 — Proven reuse
`04_SHARED/`
Only components proven reusable across episodes.

## Lifecycle
DISCOVER
→ QUALIFY
→ CREATE VIDEO PACKAGE
→ EVIDENCE RESEARCH
→ CASE/STORY MAP
→ SCRIPT
→ FACT/LEGAL REVIEW
→ PERFORMANCE REVIEW
→ SCRIPT LOCK
→ AUDIO
→ VISUAL PLAN
→ ASSET QC
→ EDIT
→ FINAL FACT/LEGAL REFRESH
→ PACKAGING
→ PREPUBLICATION
→ PUBLISH
→ ANALYTICS
→ FEED LESSONS BACK INTO CHANNEL SYSTEM

## Rule
Do not promote an episode-specific tactic into a channel-wide rule until it has proven reusable.

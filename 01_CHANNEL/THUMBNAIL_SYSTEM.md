# Thumbnail System — WHAT IT COST

Canonical visual authority:
`00_FOUNDATION/VISUAL_LOCK.md`

## Goal
One instantly readable conflict, reveal or consequence that complements the title.

The thumbnail should make a viewer ask:
**What happened, and what did it cost?**

## Channel grammar
Use:
- black / charcoal foundation;
- paper-white headline contrast;
- Signal Red `#D32222` as restrained tension/consequence accent;
- Bebas Neue-style condensed display typography;
- one dominant subject;
- one supporting evidence/context element;
- strong negative space.

Do not force every element into every thumbnail.

## Ingredients
Use only what helps:
- recognizable person/product/company;
- two opposing sides when the conflict requires it;
- authentic source document/contract fragment;
- one meaningful number;
- one consequence object/symbol;
- ownership/timeline element when essential.

## Text
- normally 0–4 words;
- maximum 5 when readability remains excellent;
- title and thumbnail should not simply repeat each other;
- use simple language;
- one highlighted word/number can use Signal Red.

## Mobile rule
Thumbnail must work before the viewer reads small evidence details.

At small size:
- primary subject remains identifiable;
- text remains readable;
- red accent still guides hierarchy;
- document texture does not become visual noise.

## Accuracy rules
- no fake document presented as authentic;
- no fabricated quote;
- no misleading crop that reverses source meaning;
- no `GUILTY`, `FRAUD`, `STOLE`, `SCAM`, `CRIMINAL` or equivalent unless the underlying status and context support that statement;
- numbers must be sourced and correctly characterized;
- allegation/complaint/charge cannot be visually upgraded into a verdict;
- company logos may be used editorially only when they do not imply sponsorship or channel ownership.

## Faces
A face is optional.

Never:
- manufacture a fake reaction from a real person;
- use AI likeness to imply the person participated in or endorsed the channel;
- use mugshot/criminal visual language unless actually relevant and verified.

## Technical master
For long-form:
- 3840 x 2160;
- 16:9;
- JPG/PNG;
- retain high-resolution editable master.

Before publish:
- test at phone size;
- inspect title + thumbnail together;
- run legal/factual packaging gate;
- run provenance/rights check.

## A/B concepts
Stage 17 should create at least three genuinely different packaging concepts where useful.

Variants should differ in:
- core visual thesis;
- subject;
- evidence;
- tension device;

not merely font size or red-bar placement.

Episode-specific concepts live in Stage 17.

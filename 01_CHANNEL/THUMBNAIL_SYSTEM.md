# Thumbnail System

## Goal
One instantly readable conflict/reveal that complements the title.

## Ingredients
Use only what helps:
- recognizable product/company/creator;
- two opposing sides;
- one document/contract fragment;
- one meaningful number;
- one consequence object/symbol.

## Rules
- one primary idea;
- minimal text, usually 0–4 words;
- mobile readable;
- title/thumbnail should not simply repeat;
- no fake document presented as authentic;
- no fabricated quote;
- no “GUILTY”, “FRAUD”, “STOLE” or equivalent unless status supports it;
- numbers must be supported and correctly characterized.

Episode-specific concepts live in Stage 17.
